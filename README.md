# MBTI 性格测试程序

这是一个使用 C 语言编写的 MBTI（迈尔斯-布里格斯类型指标）性格测试小程序。

##  项目简介
用户通过回答一系列问题，程序根据用户的选项计算出对应的 MBTI 人格类型（例如 INFP、ESTJ 等），并输出结果。

##  功能特点
- 采用控制台交互，操作简单直观。
- 包含若干道测试题，覆盖多个维度（E/I, S/N, T/F, J/P）。
- 根据得分计算出最终的 MBTI 类型。

##  如何运行
1. 点击本页面右上方的绿色 `Code` 按钮，选择 `Download ZIP` 将代码下载到本地，或者使用 `git clone` 克隆本仓库。
2. 解压后，找到 `MBTI.slnx` 文件。
3. 双击使用 **Visual Studio** 打开该解决方案。
4. 在 Visual Studio 中按下 `F5` 键，或点击顶部的“开始调试”按钮，即可编译并运行程序。

##  项目结构
- `MBTI.slnx`：Visual Studio 解决方案文件，用于打开整个项目。
- `MBTI/`：项目文件夹，包含所有源代码。
  - `源.c`：程序的主逻辑代码。
  - `MBTI.vcxproj`：Visual Studio 项目文件。
